# 城乡基建 MVP

这是基于 `docx/rules.md` 和 `docx/design.md` 制作的本地最小可行版本。

## 已实现

- 2~4 名本地玩家
- 6×6 随机地图生成
- 城市/乡村连通校验
- 每个骰子数字 1~6 恰好分配给 6 个居民点
- 开局每名玩家预建设一条道路
- 正式回合三种行动：
  1. 抽建设卡
  2. 按第一骰选择基地并修路
  3. 按第一骰选择基地，掷第二骰后修路/修桥，掷出对子时抽建设卡
- 四种建设卡：
  - 随机修路卡
  - 桥梁通路卡
  - 拆路修桥卡
  - 资金补贴卡
- 商人系统：4 位小商人 + 1 位固定大商人
- 商人最短路径、过路费结算、游戏结束与胜负判定
- 严格等概率最短路径选择：BFS + 最短路径 DAG + 动态规划计数 + 按剩余路径数加权采样
- 游戏日志和基础可视化 UI
- 固定随机种子复现
- Node 本地测试

## 运行

在项目根目录执行：

```powershell
npm test
npm run serve
```

然后用浏览器打开：

```text
http://localhost:5173
```

也可以直接双击 `index.html`，但推荐用本地 HTTP 服务运行。

## 严格等概率最短路径实现位置

核心函数位于：

```text
src/game.js
GameEngine.findUniformRandomShortestPath(startNodeId, endNodeId)
```

算法摘要：

1. 使用 BFS 计算起点到每个居民点的最短距离；
2. 仅保留 `dist[next] = dist[current] + 1` 的边，形成最短路径 DAG；
3. 从终点反向动态规划，计算每个节点到终点的最短路径条数；
4. 从起点出发，每一步按后继节点的剩余最短路径条数作为权重随机选择；
5. 因此每条完整最短路径被选中的概率均为 `1 / 最短路径总数`。
